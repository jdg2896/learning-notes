# Writing Guidelines

## freeCodeCamp

- Style Guide
- **Substance Wins the Day**
  - quotes
  - code snippets
  - data visualizations
  - at least 500 words
- **Package Your Tutorial Properly**
  - Headlines are key
    - How to fix…
    - How to build…
    - What is…
  - Add a cover image
    - use an image aspect ratio of **1.91:1**
    - use nicely contrasting colors
    - don't include too much text in images
    - simpler is usually better
    - cover images build your brand
    - don't use GIFs
  - Set the post URL (edit slug)
  - Choose tags: 1-5 tags
    - the 1st tag is the most important
- **Tips for Writing a Tutorial People Will Actually Read**
  - Grammar, spelling, and formatting do matter
    - Keep it simple
    - Use short sentences
    - Use short paragraphs
    - Clean up the punctuation
    - Use sub-headings to structure your text
    - Don't use excessive bold, italics, or both
    - Remove abbreviations
    - Use proper capitalization
    - Stay on topic
  - Use active voice ("you")
  - Add syntax highlighting to your code
  - Tutorial structure:
    - A concise introduction telling readers:
      - what they'll learn
      - what your goals are
      - and/or what they'll accomplish
    - Explain any prerequisites needed by readers
    - Walk through in a logical and organized step-by-step way
    - Use numbered lists (or subheadings) to indicate steps that should occur in a particular order
    - Pack in as much detail as you can
    - Close out with a concise conclusion reminding readers what they just learned and accomplished
  - Write longer comprehensive tutorials instead of multi-part tutorials
  - Handbooks (5,000-15,000 words)
    - add a clickable table of contents
  - Keep it G-rated
  - Use no-attribution-needed images or images/diagrams you've created yourself
    - Don't hotlink images, upload them to freeCodeCamp
    - Add alt text
  - Credit sources:
    - Quote, Source: Owner
  - No cross-posting
    - Set the canonical URL to freeCodeCamp from your own blog (personal website)
