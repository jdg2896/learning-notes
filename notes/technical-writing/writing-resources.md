## Cover Images

- Canva cover image sizes:
  - Dev.to: 1000:420
  - Hashnode: 1600:840
- Creating covers in Canva:
  - Use a brand template
  - Add the logo of the relevant project
  - Add a cute graphic
  - Add a short description title
    - Comica font, or other fonts that make it seem not too formal
  - Use design styles
